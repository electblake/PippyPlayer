# Media server references

- [DLNA / UPnP](dlna-server.md): source notation, traversal, and SOAP interrogation.
- [Stash GraphQL](stash-graphql-server.md): scene queries, saved filters, and introspection.

These references are for general audiences. Keep examples generic and save only schema metadata, never private server query results or installation details. Snapshots are partial and capabilities can vary by version. DLNA and GraphQL are distinct APIs; this documentation does not add GraphQL to PippyPlayer's playback path.
